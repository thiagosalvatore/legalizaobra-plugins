# Glossário LegalizaObra

| Termo | O que é |
|---|---|
| Obra | Uma construção, reforma, ampliação ou demolição cujo INSS será regularizado. |
| Cliente | O dono da obra. A obra é declarada no eSocial no nome (CPF ou CNPJ) dele. |
| Pedreiro / trabalhador | Quem trabalhou na obra. Fica cadastrado na conta e é ligado à obra por um vínculo. |
| Vínculo | A ligação do pedreiro com a obra: datas, cargo, CBO e tipo (MEI ou Autônomo). |
| CBO | Código da ocupação. Padrão 715210 (PEDREIRO ALVENARIA). |
| CNO | Cadastro Nacional de Obras, 12 dígitos. Obrigatório para enviar ao eSocial. |
| Área principal / complementar | Áreas da obra. A complementar coberta conta 50% e a descoberta 25% na área equivalente. |
| VAU | Valor por m² usado pela Receita para estimar o custo da obra, por estado e tipo. |
| RMT | Remuneração de Mão de Obra Total: quanto a Receita espera de mão de obra na obra. O INSS é calculado sobre ela. |
| RMT otimizado / ajustado | RMT reduzido pelo fator de ajuste (0,5 até 350 m², 0,7 acima). É o que gera a economia. |
| INSS original / otimizado | INSS sem e com a otimização do RMT. A diferença é a "Economia de INSS". |
| Concreto usinado | Concreto de usina. Gera crédito no cálculo. Guardar as notas fiscais por 5 anos, com o CNO da obra. |
| Remuneração | Valor pago aos pedreiros no mês. O sistema calcula a partir do RMT otimizado. |
| ICM % | Índice de correção monetária aplicado a meses passados. |
| CPP | Contribuição Previdenciária Patronal: 20% da remuneração. |
| Multa | Multa por atraso: 0,33% ao dia, até 20%. |
| Mora | Juros de mora sobre a CPP. |
| MAED | Multa por atraso na entrega da declaração: R$ 100 por mês atrasado, dividida entre os pedreiros do mês. |
| Encargos | Multa + mora + MAED. |
| Folha | A folha de pagamento de um mês (competência). |
| Competência | O mês a que a folha se refere. |
| Guia / DARF | A guia de pagamento do INSS de um mês. O app gera; o cliente paga. |
| DCTFWeb / e-CAC | Sistema e portal da Receita Federal onde a declaração e a guia também podem ser emitidas. |
| Certificado digital A1 | Arquivo .pfx da conta que assina os envios ao eSocial. Enviado só pelo app. |
| Procuração | Autorização que o cliente dá, no portal da Receita (gov.br), para o titular do certificado agir por ele. |
| Transmissão automática | O sistema gera a DARF do mês sozinho no último dia do mês e manda por e-mail ao cliente. |
| Aferição / SERO | Avaliação da obra pela Receita no fim, feita no e-CAC. |
| CND | Certidão Negativa de Débitos da obra. Permite averbar a obra no cartório. |
| Orçamento | Proposta de preço gerada a partir de uma simulação, para enviar ao cliente. |
